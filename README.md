# جزيرة بايثون الذكية 🏝️

مغامرة لتعلم Python للصف الثامن، مع شخصية لُمى، تشخيص المهارات، خمس محطات تعليمية، مختبر التحويل، محرر Python، تقويم نهائي وتقرير تقدم.

الموقع: https://sheikhadev.github.io/python-smart-island/

## التصميم

الصورة المرجعية دليل لتخطيط الشاشات فقط. النصوص والأزرار والخريطة والصناديق عناصر تفاعلية حقيقية. لا تُستخدم صور الشاشات خلفيات للموقع. يستخدم التصميم مشهد جزيرة خاليًا من النصوص وقصّة شفافة موحدة لشخصية لُمى.

## التشغيل والخصوصية

- شغّل index.html من خادم ملفات، أو استخدم الرابط أعلاه.
- التقدم محفوظ محليًا في المتصفح دون تسجيل حساب.
- مساعد لُمى يقدم تلميحات محلية، ولا يتصل بخادم ذكاء اصطناعي.
- مشغّل Pyodide 0.27.7 يُحمّل من jsDelivr ويتطلب الإنترنت. نجحت مهام Python الثلاث في اختبار المشغّل خارج المتصفح؛ تعثر تحميله داخل المتصفح المدمج أثناء الفحص.
- لا توجد مفاتيح API في الملفات.
- GitHub Pages: main ومجلد الجذر.
