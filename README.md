# جزيرة بايثون الذكية 🏝️

موقع تعليمي تفاعلي للصف الثامن مع شخصية لُمى: تشخيص المهارات، مسار مقترح، ألعاب تعليمية، مختبر التحويل، محرر Python، وتقويم ختامي وتقرير تقدم.

## التشغيل

افتح الموقع: https://sheikhadev.github.io/python-smart-island/

أو شغّل ملفات الموقع عبر خادم ملفات محلي. مشغّل Python (Pyodide 0.27.7) يُحمّل من jsDelivr عند أول تشغيل ويتطلب الإنترنت.

## الخصوصية وحدود النسخة

- يُحفظ التقدم محليًا في متصفح الطالب دون تسجيل حساب.
- مساعدة لُمى تلميحات محلية جاهزة؛ لا تتصل بخادم ذكاء اصطناعي.
- لا توجد مفاتيح API في المشروع.
- الرسومات مرسومة بتأثير ثلاثي الأبعاد، وليست نماذج قابلة للدوران.

## النشر

GitHub Pages: الفرع main والمجلد الجذري (/). ملفات الموقع: index.html وassets/.
